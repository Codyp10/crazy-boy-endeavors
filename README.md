# Crazy Boy Endeavors — Landing Page

A modern, tough, no-nonsense single-page website for Brian Wuerstlin's custom fabrication business in Falling Waters, West Virginia.

## What's Included
- Fully responsive, dark industrial design (manly + modern + capable)
- 7 custom photorealistic images generated specifically for this site using Grok Imagine
- Working mobile navigation
- Clickable portfolio with detailed project modals
- Direct phone + email CTAs + working contact form (opens your mail app with pre-filled details)
- All real project stories and details from Brian's actual work (hybrid mower, dump trailers, V-plows, hardscaping, etc.)

## How to View the Site
1. Open `index.html` in any modern browser (Chrome, Safari, Firefox, Edge).
2. That's it. No build step, no dependencies.

## How to Host It (Recommended)
- **Easiest**: Drag the entire folder (index.html + assets/) onto [Netlify Drop](https://app.netlify.com/drop) — instant free hosting + custom domain later.
- **Vercel**: `vercel --prod`
- **GitHub Pages**: Push to a repo and enable Pages.
- **Any static host** works perfectly.
